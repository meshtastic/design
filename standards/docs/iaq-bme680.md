# IAQ for BME680

Indoor air quality (IAQ) data for the BME680 sensor.

## IAQ Scale

The IAQ index ranges from **0 to 500**:

| IAQ Range | Air Quality          |
|-----------|----------------------|
| 0–50      | Excellent            |
| 51–100    | Good                 |
| 101–150   | Lightly polluted     |
| 151–200   | Moderately polluted  |
| 201–250   | Heavily polluted     |
| 251–350   | Severely polluted    |
| 351–500   | Extremely polluted   |
